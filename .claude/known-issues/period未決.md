## 「宋」四千五百六十二條：一個**被推翻的**判準

初擬之判：「dynasty 為宋而不見於任何宋以前之志者，是趙宋」——
以為劉宋之書必見於隋志唐志。

**以庫中已明標「南朝宋／劉宋」之八十五條驗之，此判不成立**：

| | 條 |
|---|---|
| 明標劉宋而**無**宋前志書者 | **77** |
| 明標劉宋而有宋前志書者 | 8 |

九成的劉宋之書在庫中只見於《國史經籍志》（明）與四庫一系的晚出目錄。
故「無宋前志⇒非劉宋」是假的，**不用**。

要決此四千五百餘條，須另尋判準。可試者：
- 繫 `entity_id` 者，看該 entity 之生卒或所繫他書；
- 四庫提要之 `author_info` 每作「宋某某撰」，其上下文或可別南北；
- 以書名之類目與內容判（劉宋之書多見於《隋志》所著錄之類）。

**在找到可自驗之判準以前，一律留 null。**

## 附：斷代志之自驗（此軸最要緊的一步）

判「無朝代而所著錄之志唯一且為斷代志者」時，何者是斷代、何者是通代，
**以庫中資料自驗**——看該志所著錄之書，撰人朝代之分佈：

| 志 | 主朝代佔比 | 判 |
|---|---|---|
| 明史藝文志 | 明 **98%** | 斷代 |
| 清史稿藝文志 | 清 **94%** | 斷代 |
| 後漢藝文志 | 東漢＋漢 **98%** | 斷代 |
| 補晉書藝文志 | 晉 **96%** | 斷代 |
| 元史藝文志／補遼金元藝文志 | 元金遼 **96%** | 斷代 |
| 三國藝文志 | 三國諸目 **93%** | 斷代 |
| **宋史藝文志** | 宋僅 **51%**（唐 18%、漢 6%） | **通代** |
| 國史經籍志 | 明 23%／宋 21%／唐 18% | 通代 |
| 崇文總目 | 唐 43%／漢 12%／宋 12% | 通代 |
| **舊唐書經籍志** | 唐＋隋僅 49／320（15%）；晉＋三國魏吳蜀等前朝合計 234（73%） | **通代**（收錄前朝遺書，不可代填 `sui-tang`） |

**宋史藝文志是通代**。初版把它當斷代，一舉要把八千三百三十六條無朝代者判為 `song`——
此驗攔下了。凡欲以某志定時代，先做這個分佈。

漢書藝文志雖亦近斷代（漢 53%＋周 31%＋上古 7% ＝ 91%），然**跨先秦與秦漢兩段**，
不能定於一，故只作上限用。
