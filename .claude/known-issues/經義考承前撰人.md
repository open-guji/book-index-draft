# 經義考之「裸題承前撰人」例（2026-08-23 A11 車道所發）

> **凡動《經義考》（`1ev3bb43bv4lc`）之節者必先讀此篇。**
> D1 車道正為其 4,776 無繫連之節鑄 work；若不知此例，所鑄之書撰人必錯，
> 而撰人一錯則斷代（C 類）、併池（B 類）俱隨之錯。

## 一、例

朱彝尊《經義考》之著錄，**撰人只題於一人諸書之首條**，其下同撰人之書一律裸題，
承前條之撰人。體例與《直齋書錄解題》同，而《經義考》尤密——一人動輒連著五六書。

    易 #687  朱子（熹）易傳    宋志十一卷  佚
    易 #688  周易本義        宋志十二卷  存      ← 朱熹
    易 #689  易學啟蒙        宋志三卷   存      ← 朱熹

    通禮 #108 亡名氏禮論鈔    隋志六十九卷 佚
    通禮 #109 禮論要鈔       隋志十卷   佚      ← 亡名氏
    通禮 #110 禮雜問        隋志十卷   佚      ← 亡名氏
    通禮 #111 禮雜答問       隋志八卷   佚      ← 亡名氏

**闕名之書亦然**：以「亡名氏X」起一段，其下裸題諸條俱是無名氏之書，
**不得**因題名撞庫而繫到某有名之人的同題書上。

## 二、量

全志書節 8,069，**裸題 1,452（18%）**。其中已繫 649、無繫連 778（餘為體例節）。
已繫之 649 條，以「承前撰人」覆核：

| 覆核之結果 | 條 |
|---|---:|
| 承前撰人與所繫 work 之撰人相合 | 115 |
| 所繫 work 無撰人（無從覆核，多半亦合）| 246 |
| **承「亡名氏」而所繫之 work 有撰人**（可疑）| 118 |
| **承前撰人而與所繫 work 之撰人不合**（可疑）| 112 |

## 三、覆核可疑條時的三個假警報

1. **同人異名**。吳澂／吳澄、干寳／干寶、焦延壽／焦贛、俞琰／俞琬、晁説之／晁說之
   ——是異體與字號，非二人。
2. **另一種撰人格式，非裸題**。志中尚有「明氏僧（紹）孝經注」「南平王蕭（偉）周易幾義」
   「釋（希覺）周易會釋記」「司馬（光）易説」「江翁孝經説」數式，
   撰人在題內而不作「某氏（某）」，機讀易誤判為裸題。判可疑之前先剔之。
3. **work 側撰人帶衍字**。「郡陸德明」「溪范諤昌」「宋咸貫之」「龔原深之」之屬，
   是他志匯入時把地望或字號黏進了姓名，屬 B 類之事，非本例之錯。

## 四、真缺陷之形

剔去上三者，所餘即真錯掛，其形是「**裸題撞庫，撞到同題而他人之書**」：

| 節 | 承前撰人 | 誤繫 | 正 |
|---|---|---|---|
| 易 #689 易學啟蒙 | 朱熹 | 吳迂《易學啟蒙》| 朱熹《易學啟蒙》|
| 易 #686 讀易紀聞 | 呂祖謙 | 張獻翼（明）《讀易紀聞》| 呂祖謙 |
| 易 #608 易圖 | 陳知柔 | 端木國瑚（清）《易圖》| 陳知柔 |
| 通禮 #110 禮雜問 | 亡名氏 | 范寧《禮雜問》| 亡名氏 |
| 周禮 #34 周官禮圖 | 亡名氏 | 俞言《周官禮圖》| 亡名氏 |
| 儀禮 #195 喪服要略 | 亡名氏 | 環濟《喪服要略》| 亡名氏 |

**其共同之形**：時代往往相隔數百年（宋 ↔ 明、宋 ↔ 清），
是「只按題名撞庫、不驗撰人」所致——與 A6 舊唐志、A10 補遼金元所犯者同一種病。

## 五、給 D1 的話

為裸題之節鑄 work 時，**撰人取承前之人，不得留白，亦不得由題名猜**。
一段之首條若是「亡名氏X」，其下裸題所鑄者撰人留空並記其為闕名，
**切不可**因題名在庫中有同題之書而逕繫之。

# 附：A11 一輪三分之實績（2026-08-23）

## 一、所用之檢測——「一 work 多節」，非「磁鐵」

磁鐵只查**異題**共指一 work，故《論語注》王濛條下四節之中，
同題者（二《論語解》）查不出。改以「**一 work 繫本志二節以上**」為檢測，
得 35 組（磁鐵只得 32 組 68 題）。**他志亦當補此一檢測。**

## 二、判準

以「承前撰人」定各節之撰人，而後：

- **諸節撰人同、題亦同** → 一書兩見，非缺陷。
- **諸節撰人同而題異** → 多是一人數書（朱升《四書旁注》《大學中庸旁注》《三禮旁注》）
  或總目與分經（胡旦《演聖通論》六十卷 ↔ 《周易演聖通論》十六卷、
  《春秋演聖通論》十卷），**拆**，分經者以 `part_of` 繫其總。
- **諸節撰人異** → 拆，惟三種假警報（見上篇〈三〉）不拆。

## 四、所辦

**鑄 36、改繫 2、撤誤掛之著錄 21。** 經義考磁鐵 52→2，「一 work 多節」35→5（俱非缺陷）。

最要者數事：

- 易 #689《易學啟蒙》承朱熹，原繫元吳迂之同題書——**庫中舊無朱熹《易學啟蒙》本書**，
  只有其衍書八種（翼傳、注、意見、類編、圖傳通義……），今始立。
- 論語《論語注》（王濛，東晉）一條之下，竟掛著八條經義考著錄
  （王肅、王令、王安石、王端禮、王鞏、王蘋、王綯、王炎），
  是「姓氏『王』＋通題」撞庫之積誤。四節拆出、四條著錄撤去；
  其中王綯、徐椿年、徐存三人之書本無繫連而著錄誤掛他條，亦一併立之。
- 詩《詩集傳解》二節俱題「高頥」而實二人——宋慶元進士高頥三十卷、
  明洪武舉孝廉高頥二十卷，**同姓名而異代**。
- 書 #34《古文尚書注》承王肅（節文引劉知幾「王肅注今文尚書大與古文孔傳相類」），
  原繫後漢張楷《尚書注》。
- 春秋 #105《春秋釋例》承杜預（節文引黄澤「杜元凱作春秋經傳集解之外自有釋例一部」），
  原繫潁容之十卷本；撞庫得杜預十五卷本，改繫。
