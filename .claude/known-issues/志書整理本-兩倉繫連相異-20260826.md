# 志書整理本：兩倉繫連相異（2026-08-26，已辦竣）

**狀態：已辦竣。** 起於昨日 draft 資產清理時發現四部志書整理本兩倉內容有異，
記錄存疑；本日以逐行 `git log -L` 精確追溯歷史，剔除機械提交（分片改制、
升格拷貝、引用歸一 sweep），取兩側各自「最後一次真判斷」之時間定勝負，
逐一辦畢。

## 方法

先以 `git blame`／`git log -p` 直測，發現機械提交之時間戳會嚴重誤導——
`promote` 拷貝與 `sweep-promoted-refs` 皆會「觸碰」某行而改其字面值，
但那只是把 draft-id 換算為其升格後之 production-id，並非獨立判斷。
故改用 `git log -L <行>,<行>:<檔>` 精確取得該行之完整值鏈，逐一核對
每次改動是否僅係「該值經 promotions.json 映射為另一形」；若是則跳過，
續看更早一次；直到找到兩側各自**最後一次非機械**之改動，以其時間定勝負。
