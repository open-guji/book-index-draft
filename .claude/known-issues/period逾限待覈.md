# `period` 與 `period_upper` 相斥者（216 條）

2026-08-21。逐條清單見同名 `.json`。

## 由來

catalog_bound 覆驗全庫，初得 **437 條** `period` 逾其著錄志之上限。已處置者：

| 批 | 條數 | 處置 |
|---|---:|---|
| 跨代人物（遺民） | 191 | **已改判**——從斷代志。宋遺民鄭思肖、林景熙、陳允平等歸 song；元遺民陶宗儀、危素等歸 liao-jin-yuan |
| duandai 清史稿漏洞 | 119 | **已撤 period**——清史稿「輯佚」子目著錄清人所輯之古書，不可據以判 qing |
| 清史稿著錄語朝代前綴 | 27 | **已訂正 dynasty**——蔡邕、包咸標漢為清，范宣、庾翼標晉為清之屬 |
| **餘** | **216** | 本清單 |

## 兩類

### A 早志著錄語含本條撰人名（36 條）

早志明書撰人之名，則撰人確係彼時人，或該志誤收。二者須分：

| 例 | 情形 |
|---|---|
| `1evcmnf6fmj28`《六情決》 | 隋志「《六情決》一卷王琛撰」——王琛是隋以前人，Work 標「明」錯 |
| `1evcpctk2wh6o`《禮記略解》 | 舊唐志「庾蔚之撰」——南朝宋人，Work 標「清」錯 |
| `1evcua75leyv4`《老子嗣古注》 | 舊唐志「《老子》二卷陳嗣古注」——唐人，Work 標「宋」錯 |
| `1ev3bc3y0l43k`《捫蝨新話》 | 宋志「陳善《捫虱新話》八卷」——宋人，Work 標「明」錯 |
| `1ev3bb5b1pngg`《涉史隨筆》 | 補晉志「涉史隨筆一卷 葛洪」——**志書誤收**：此書是南宋葛洪撰，補晉志編者誤作晉葛洪。本庫 period=song 是對的 |
| `1evrbhp6ajqx8`《詩韻大成》 | 宋志補「胡繼宗撰」——而胡繼宗是明人（《書言故事》作者）。誰誤，待覈 |

**不可機械處置**——「本庫錯」與「志書誤收」判反了就把對的改壞。

### B 早志著錄語不含本條撰人名（180 條）

早志所錄與本條撰人全不相干，多是同題異書被併為一條：

| 例 | 早志所錄 | 本條 |
|---|---|---|
| `1ev3b9zs0ly4g`《書儀》 | 隋志「《書儀》二卷蔡超撰」 | 司馬光《書儀》 |
| `1evcsz1rvbsow`《杜詩》 | 宋志「王洙注《杜詩》三十六卷」 | 鮮于樞《杜詩》 |
| `1ev3bcr5c97uo`《陰符經注》 | 宋志「太公等《陰符經注》一卷」 | 徐大椿《陰符經注》 |
| `1ev3bafkvo8hs`《明良集六種》 | 崇文「明良集五百卷」 | 霍韜《明良集六種》 |

**處置**：把早志之節自本條摘出，另建 Work 或改繫庫中已有者。屬「著錄掛錯」專項，
與先秦磁鐵拆解同型，宜另立一輪批量做。
