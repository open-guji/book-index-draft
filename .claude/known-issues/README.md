# 已知缺陷登記

**此處記的都是「查清了、但決定暫不修」的東西。** 每條須寫明：範圍（有多少）、
成因（為何如此）、為何暫不修、以及**修的時候會踩到什麼**。

只寫「有問題」而不寫成因與範圍的，不要放進來——那種東西下次還得從頭查一遍，
記了等於沒記。

## 為何要有這個目錄

本庫的缺陷有一大類**不觸發任何校驗**：欄位有值、非空、無懸空關聯，`chk.py` 全綠，
但語義是壞的。它們的代價不在當下，而在**下一次整理時把你引向錯誤的結論**——
最常見的形態是「庫中查不到 → 新建 → 重出」。

所以這裡的每一條，實質上都是一張**動手前的對照表**。
