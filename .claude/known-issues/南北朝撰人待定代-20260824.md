## 為何餘下 213 人做不了

長尾：213 人中 **211 人只涉一至二條**。其名多只見於一處志書著錄，而該著錄
不冠朝代（如《國史經籍志》之「《某書》N卷（某某）」括注體），亦無本傳可引。

三路皆窮：

1. **引文無朝代語**——本輪之逐條抽法對這批全數落空（262 人 / 313 條次無命中）。
2. **entity 無 dynasty**——其 entity 多是據同一條著錄新建，本身即無代可傳。
3. **不可據同名他代之人回填**——本輪已見數例（王逸之於東漢王逸、明粲之於宋人晏乂、
   劉芳之於明劉芳），機械同名回填正是 README 所戒之「entity 誤配名實不符」。

## 追記（2026-08-25）：第四路——隋志塊承

N4 之「逐條引文定代」限**不跨句、十二字內**，對《隋書經籍志》集部那種
「一標統數十家」的長條全數落空。今放寬為**逐塊承接**：

> 隋志集部之體是「〔朝代〕〔官銜〕《某集》N卷」，且**逐朝成塊**——
> 一塊之首標朝代，其後同朝諸家承之而不再標。故某人之代＝其名之前
> 最近一個**真**朝代標記。

四道濾網去偽（少一道則精度掉三五個百分點）：

1. **書名中之朝代字先挖空**——《齊紀》《齊民要術》《晉書》《梁選簿》之「齊」「晉」「梁」
   是書名之字，非朝代標記。誤判之大宗。
2. **「梁十卷」不算**——此「梁」謂《七錄》（梁目）所記之卷數；
   **「梁有」「梁又有」亦不算**——謂梁目有而今亡之語。
3. **封號與郡縣名不算**——「後周齊王」之「齊」、「陳思王」之「陳」、
   「晉安太守」「晉陵令」之「晉」。
4. **已為前一家所用者不算**——標記與其名之間隔了「撰；」者。

又：標記須與其名相隔 **1–20 字**。緊貼者多是卷數之殘（「…二十卷梁元懌」），
太遠者其間已另起一家（「梁有晉中軍功曹《殷曠之集》…周續之」）。
