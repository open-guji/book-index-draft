# A 類跨卷磁鐵之覈定（2026-08-23，chk 第四盲區補後）

`chk.py` 舊法於每個 `collated_edition/*.json` 檔內另建磁鐵表，故一整理本之諸卷各自為政，
**跨卷之磁鐵一概查不出**。補正之後全庫磁鐵 275→687、A 類 251→639。
本篇記新暴之各組何以是缺陷、何以不是。

## 一、新暴之最大一型：注本／鈔本繫到撰人之別集上（A6 兩唐志，七組）

新唐志之題作「某人某書」，匯入時以撰人之別集題為前綴撞庫，遂有：

| 節 | 誤繫 | 正 |
|---|---|---|
| 何晏集解十卷 | 《何晏集》十卷 | 何晏《論語集解》 |
| 孫綽集解十卷 | 《孫綽集》十五卷 | 孫綽《論語集解》 |
| 范甯集注十二卷 | 《范甯集》十五卷 | 范寧《春秋穀梁傳集解》十二卷 |
| 李顒集注十卷 | 《李顒集》十卷 | 《集注尚書》（隋志「集注尚書十一卷，李顒注」）|
| 陶弘景集注神農本草七卷 | 《陶弘景集》三十卷 | 《神農本草》（陶隱居）|
| 丘遲集鈔四十卷 | 《丘遲集》十卷 | 新立（鈔本自成一書）|
| 諸葛亮集誡二卷 | 《諸葛亮集》二十四卷 | 《諸葛武侯集誡》二卷 |

**其形**：節題＝「別集之題」＋「解／注／鈔／誡」。他志同體例者當以此為式自查。

## 二、同題異書之三例（A6／A9）

| 組 | 判 |
|---|---|
| 《隋書》八十五卷（魏徵等）／八十卷（王劭）| **拆**。王劭之隋史早出而亡，非正史 |
| 《古今注》八卷（伏無忌）／五卷（崔豹）／三卷（崔豹）| **拆伏無忌一支**；崔豹之三卷五卷一卷是一書之異本 |
| 《雜語》五卷（隋志小說家）／三卷（隋志雜家）／孫盛（補晉志附錄）| **拆為三**。二類二卷不著撰人，孫盛者即《異同雜語》 |
| 《論集》七十三卷（隋志總集）／八十六卷（殷仲堪，隋志雜家）| **拆**。撰人卷數俱異 |
| 《雜議》五卷（干寶）／十卷（補晉志刑法，闕名）／十二卷（吳商）| **拆為三** |
| 《神仙傳》十卷（葛洪）／《神仙傳略》一卷 | **拆**。補晉志自云「疑後人删取葛氏《神仙傳》為之」 |

## 三、覈定為非缺陷者

| 組 | 何以不是缺陷 |
|---|---|
| 《列女傳敘贊》／《列女傳序贊》一卷（孫夫人，兩唐志）| 敘／序之異體 |
| 《游玄桂林》九卷／二十一卷（張譏，隋志論語類・道家類）| 一書而隋志兩類互見，撰人同 |
| 《搜神後記》／《搜神後記十卷》（陶潛，補晉志）| 補晉志自注「互見雜傳類」 |
| 《古今注》三卷／一卷（崔豹，補晉志）| 同上，兩類互見 |
| 《晉雜議》／《晋雜議》十卷（補晉志儀制類・舊事類）| 晉／晋 異體，兩類互見 |

**「互見」二字是判非缺陷之硬證**——補晉志、經義考、直齋俱有此例，
一書兩類並著，其節自當共繫一條。
