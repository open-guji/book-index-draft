# E1 人物併池（同一人被拆成二 Entity）

2026-08-22 立。**成因**：匯入之際人名寫法不一（異體、簡繁、古今字），
遂為同一人建了兩條 Entity。其害有二：其人之作品散在兩處，「選某人之作品」壞掉；
且其一之朝代若誤，會順著 `authors[].dynasty` 傳播（顏延之一條誤標「唐」而掛 28 部書）。

## 判準

| 條件 | 判 |
|---|---|
| 歸一後同名（異體）＋朝代同＋生卒年不相斥 | **可併** |
| 名字面全同＋朝代同，而無生卒年可佐 | **不可併**——同名同代未必一人 |
| 生卒年相斥 | **不併** |

**CBDB id 不同不足以證明是二人**：實測黃幹（1152–1221）、洪适（1117–1184）、
顏真卿（709–784）皆兩條 Entity 各有一個 cbdb_id 而生卒年全同——是 CBDB 自身之重出，
或匯入時各取一 id。真正相斥者是生卒年（舒岳祥 1219／1236、莊昶 1411／1437）。
故併時 CBDB 另予之 id 存於 `external_ids.cbdb_id_alt`，不棄。

## 第三批（2026-08-22）：歸一順序訂正後之補捕 4 組

**前兩批之歸一化有序之誤**：先跑 OpenCC 簡化、後套異體表，
而異體表所映射者是繁體字形（灃→澧、湻→淳、寛→寬），
簡化既已先行，該表遂永不觸發——`陳灃` 歸一得「陈沣」，`陳澧` 得「陈澧」，
兩不相值。**正法是先套異體表、後簡化。** 訂正後補捕：

  陳澧／陳灃（清，1810–1882）　葉名澧／葉名灃（清）
  汪克寬／汪克寛（明，1304–1372）　陳淳／陳湻（南宋，1159–1223）

**此誤之教訓**：凡「歸一之後比對」者，須驗**歸一之序**——
異體歸一在前、簡繁轉換在後，反之則異體表失效。

### 一、王期／王愆期／王懋約四條：併一、分二、仍扣一

| entity | 前 | 今 |
|---|---|---|
| `1j96hfbhtlon4`「王　期」晉 | 待覈 | **正名為「王愆期」**，`1j96hlg4kx62o` 併入 |
| `1j96hlg4kx62o`「王愆期」明 | 待覈 | **退役**（works 空，dynasty「明」乃自動回填之誤） |
| `1j96heyqapw5c`「王懋約」無代 | 待覈 | **補代「晉」**，判與王愆期非一人 |
| `1j96hfcnspibk`「王期」晉 | 待覈 | **仍分立**，然其由已易（見下） |

**「王　期」即王愆期，有一一相合之證**。本條所繫《春秋公羊經傳注》出《補晉書
藝文志》，文作「散騎常侍王　期，謹按見《隋志》」——空格即闕字之痕，而姚振宗
自注其所本是《隋志》。檢庫中《隋書經籍志》整理本春秋類，正作
「《春秋公羊經傳》十三卷　**晉散騎常侍王愆期注**」：題同、卷同、官同、代同，
**四者一一相值**，所闕之字是「愆」。

同志同類又載「《春秋公羊論》二卷，晉車騎將軍**庾翼問，王愆期答**」——
庾翼（305–345），故王愆期是**東晉**人。

**王懋約非王愆期**。《隋書經籍志考證》（姚振宗）於《禮記寧朔新書》下云：
「按王懋約始末未詳。其為燕王師者，蓋燕王機，文帝子也。……又《晉書·儒林·
陳邵傳》云：『邵於泰始中為燕王師。』則又與邵同時同官。」泰始（265–274）
為西晉武帝年號，故王懋約是**西晉初**人，與東晉之王愆期相去六七十年，官職
亦異（燕王師／散騎常侍）。**且姚振宗詳論王懋約而明言「始末未詳」，未嘗以之
與王愆期相牽**——以姚氏之縝密，若二名一人，不當不著一語。

（「懋約」與「愆期」於名字之義可相配（期／約），前輪疑其為一人之名字，
是有理由的疑；今以年代、官職、姚氏之不言三事斷為二人。）

**《降幕祠儀》之「王期」仍扣**，然理由已非「四條未合勘」。今合勘畢而此條仍
不可決者：《補晉書藝文志》著《降幕祠儀》作「王期」而**無闕字之痕**，著
《春秋公羊經傳注》作「王　期」而空格宛然——**同一姚氏之書，一有闕痕一無，
是姚氏自別其異**；且儀注與公羊之學不相涉，別無字號里貫可佐。欲決之須覈
《太平御覽》樂類原文，非本庫所藏之證能辦。

### 二、劉熙三條：三條實三人，一條也不當併

前記「其唐、明二條疑誤」。今覈之，**疑不成立**：

- **唐條**（`1j96hll171yps`）繫《劉熙注范曄後漢書》。范曄（398–445），
  注其書者必在其後；東漢劉熙（《釋名》撰人）約當二世紀末，**相去二百餘年，
  時代相牴，不得併**。
- **明條**（`1j96hhvcr8mx1`）字孟雍，繫《衡山縣志》明弘治元年刊本，明人無疑。

前輪之疑生於只比名字面。**三條之分立是對的，非重出。**

**惟唐條之 dynasty「唐」所據甚薄**——只是該書見於《新唐志》。一書見於某志，
其人不得晚於該志，是**上限**非定判；《新唐志》兼錄前代之書，注范曄者可以是
南朝、可以是隋。今可確言者只「在范曄之後」一事。交斷代道。

### 判準之易：不憑 CBDB id，改憑提要所著之撰人小傳

前輪之例「凡 CBDB id 各異而生卒可別者，一概判為二人」**已證其非**——
本輪 35 群之併，其中十餘群正是二條各有 cbdb_id 而實為一人。
今之法：以**四庫總目提要**與各志書著錄所帶之撰人小傳（字、號、里貫、官歷、所著之書）
為斷，四者有二者相合而無相牴，即斷為一人；
同名同代而所著之書全不相涉、里貫或字相異者，斷為二人。

**最有力者是「二條所繫實一書」**——十四群由此而決：
《河治通考》＝《治河通考》（吳山）、《鶴林集》＝《鶴林文集》（吳泳）、
《東溪日談錄》＝《居業錄卷東溪日談》（周琦）、《韓忠獻遺事》＝《韓魏公遺事》（強至）、
《南詔通紀》＝《南詔通志》（楊鼐）、《紫山先生大全集》＝《紫山大全集》（胡祇遹）、
《莊定山集》＝《定山集》（莊昶）、《玉芝堂集》＝《玉芝堂文集》＋《詩集》（邵齊燾）、
《石堂遺集》＝《石堂先生遺集》（陳普）、《喪服儀》（衛瓘）、
《太元真人東鄉司命茅君內傳》之長短題（李遵）等。

**次有力者是提要之自相牽引**：四庫於《春秋左傳句解》《孝經句解》皆云
「申有《周禮句解》，已著錄」——朱申二條遂決；於《海內名家工畫能事》
《文選纂注》《處實堂集》皆云「鳳翼有《夢占類考》，已著錄」——張鳳翼三條遂決。
