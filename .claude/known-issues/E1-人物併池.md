# E1 人物併池（同一人被拆成二 Entity）

2026-08-22 立。**成因**：匯入之際人名寫法不一（異體、簡繁、古今字），
遂為同一人建了兩條 Entity。其害有二：其人之作品散在兩處，「選某人之作品」壞掉；
且其一之朝代若誤，會順著 `authors[].dynasty` 傳播（顏延之一條誤標「唐」而掛 28 部書）。

## 判準

| 條件 | 判 |
|---|---|
| 歸一後同名（異體）＋朝代同＋生卒年不相斥 | **可併** |
| 名字面全同＋朝代同，而無生卒年可佐 | **不可併**——同名同代未必一人 |
| 生卒年相斥 | **不併** |

**CBDB id 不同不足以證明是二人**：實測黃幹（1152–1221）、洪适（1117–1184）、
顏真卿（709–784）皆兩條 Entity 各有一個 cbdb_id 而生卒年全同——是 CBDB 自身之重出，
或匯入時各取一 id。真正相斥者是生卒年（舒岳祥 1219／1236、莊昶 1411／1437）。
故併時 CBDB 另予之 id 存於 `external_ids.cbdb_id_alt`，不棄。
