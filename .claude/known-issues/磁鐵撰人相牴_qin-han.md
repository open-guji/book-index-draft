# 秦漢段磁鐵普查（2026-08-21）

## 判準改了

舊判準「一條挂 ≥3 節且題名 ≥3 種寫法」——秦漢段掃出 **241 條**，逐條看去
幾乎全是誤報：《論衡》十節十題、《風俗通義》八節八題，志書各記其題本是常態，
題名寫法多**不是**一書被當磁鐵之證。

新判準：**著錄節所點明之撰人與本條 `authors` 相牴**（`scripts/detect_magnet.py`，
判名之法在 `scripts/magnet_lib.py`）。241 → **56**。

判名要過八道閘，每一道都是踩出來的：

| 閘 | 何以立 |
|---|---|
| 一、本條撰人之名先剔 | 一節可以既書撰人又書注者（「張衡二京賦二卷傅巽注」），整節放過則注者漏網 |
| 二、異體字先歸一 | 說／説、眾／衆、揚／楊、鹹／咸——不歸一則題名剔不淨 |
| 三、書名號內、卷數先剔 | 不剔則《韓詩外傳》之「傳」、《風俗通義》之「義」被當役字，題名末字誤作人名 |
| 四、所取之語若為題名之省稱則棄 | 「韓外傳」是《韓詩外傳》之省，不是人 |
| 五、撰人語必起於句首或界隔之後 | 「古文論語注」之「文論語注」上承一「古」字，是題名之殘 |
| 六、人名與題名不共二字連文 | 「古文論語」與《論語訓說》共「論語」 |
| 七、或云、舊題之屬不取 | 「或云子貢所作」是異說，非本志所定之撰人 |
| 八、節既書本條撰人，其節即屬本條 | 隋志「《神異經》一卷東方朔撰，張華注」——注者是附記，不是另一書之著錄。**真當拆者，其節無撰人而唯有注者**（舊唐志「又四十卷酈道元注」） |

另有「梁有…亡」之附記語須先截去——隋志「《毛詩》二十卷…毛萇傳，鄭氏箋。
梁有《毛詩》十卷，馬融注，亡」，馬融非本條之撰人。
