# 整理本繫連（work_id）而 work 側無本志著錄——A1–A5 之殘餘 49 條

**範圍**：`chk.py` 新增之「整理本繫連（work_id）而 work 側無本志著錄」一項，
2026-08-23 全庫實測 538，其中 A1–A5 五志佔 429。本輪已處置 380
（補著錄條 315、改繫 65），**餘 49 條記於此，皆已查明成因而暫不修**。

## 成因

`chk.py` 舊有之「整理本繫連而 work 側無記錄」只查 section 之複數 `work_ids`，
而全庫繫連絕大多數走單數 `work_id`——那一路從來沒查過，所以該項長年報 0。
本輪補查 `work_id`，這一大批才浮出來。

一條「無本志著錄」有兩種可能，**方向相反**：

1. **繫連是對的，缺的是著錄條** → 補 `indexed_by`；
2. **繫連是錯的**（匯入只按題名比對，不看撰人） → 改繫。

分辨全靠撰人。本輪 65 條屬第二型，多是宋志之節誤繫到明清同名之書。

## 為何暫不修

### 甲、宋史藝文志 40 條——體例所限，機械取不到撰人

宋志一條作「撰人《書名》卷數」，**撰人前置**；匯入切分時，
一條之末所見之人名其實是**下一條**的撰人（skill〈宋史藝文志的尾名陷阱〉）。
凡節文有前置撰人者，本輪已據以改繫（46 條）。**餘 40 條節文無前置撰人**，
其撰人在志文中承前而省（「又《詩集》十卷」之屬），
或落在前一節之末——skill 明言「凡條目末尾出現人名，一律棄權，
**不要用『回推前一條』的規則**」，故一律不猜。

其中八組尤須留意，是**同一個 work 收了一票不相干的節**：

非讀原文不能辦，故本輪不辦。

逐條之疑：

- **《禮部韻略》五卷（王□等修。）**——原修者丁度等，庫中另有《附釋文互注禮部韻略》
  （丁度）與《增修互注禮部韻略》（毛晃增）。「王□」缺字未得，不能定是何本，故不動。
- **《孝經》•一卷（國朝朱軾注）**——朱軾注本，非白文之《孝經》。依 skill
  「《禮記》與《禮記鄭玄注》是兩個作品」，當別立 work，庫中無之，待鑄。
- **《文章正宗》二十卷、《續集》二十卷**——所繫者《續文章正宗》，
  而本節之提要說的是正編。正編之 work 庫中無之。且一節二書，須先拆。
- **《皇明寶訓》四十卷（明呂本等輯）**——所繫之 work 撰人作「陳治本」，
  未詳所本；二者是否一書待覈。
- **《春秋集解》十二卷（清應撝謙）**——所繫者蘇轍《春秋集解》。應撝謙之本
  庫中無獨立 work（只有《校補春秋集解緒餘》），待鑄。
- **《公羊傳》不分卷 穀梁傳不分卷（清王源評訂）**——一節二書，且是評訂本，
  現繫《公羊傳》白文。拆與不拆待議。
- **《集古梅花詩》十九卷（清張吳曼等撰輯）**——所繫者童琥本。二者關係待覈。
- **《皇華集》二十四卷（明朝鮮官府編）**——《皇華集》乃明使與朝鮮文臣唱和，
  歷朝各有其集，所繫者華察本。二十四卷本屬誰待覈。
- **清史稿「《古論語》十卷」**——現繫《論語》白文之 work。《古論語》是《論語》
  之古文本，作一書或作異本，待議（涉 SCHEMA〈一條 Work 記錄代表什麼〉）。
