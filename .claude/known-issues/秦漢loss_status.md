# 秦漢一區 `loss_status` 覆核（2026-08-06）

**狀態**：秦漢一區（`period: qin-han`）1,658 條中，原無 `loss_status` 者 1,176 條。
本輪補 **48 條**（皆 `lost`，據《後漢藝文志》姚振宗逐條引錄之隋志「梁有……亡」）。
**餘 1,128 條未動**——試過三路，兩路已驗證不可用，詳見下。

## 為何大宗集中在《後漢藝文志》

1,176 條無 `loss_status` 者，593 條（過半）出自單一來源《後漢藝文志》（姚振宗）。
此志體例是**散文考證**，逐條夾敘本傳、諸家著錄、後人輯本、按語考辨，
與《隋書經籍志》注「梁有……亡」那種**terse、formulaic** 的體例截然不同。

## 兩路已試而不可用（偽陽過半，逐一驗過）

### 一、單字關鍵詞（亡／佚／存／闕……）

命中即以百計，然「見」「存」「亡」等字在考證散文中隨處而有，不可信。

### 二、加「此書／是書／原書」等自指詞——**仍不可用**

看似比單字嚴謹，抽驗三十餘候選仍有七例明顯偽陽（含兩例**判準會判反**）：

| 條目 | 命中之句 | 實情 |
|---|---|---|
| 大戴禮記 | 「是書猶存其十篇」 | 「是書」指《曾子》，非本條 |
| 交州異物志 | 「至吳時尚存」 | 尚存者是**人**（楊孚），非書 |
| 急就篇解 | 「不應…六十餘年尚存」 | 尚存者是**人**（曹世叔），非書 |
| 黽池五瑞圖 | 「今墓與石室尚存」 | 尚存者是**墓與石室**，非書 |
| **崇德正論** | 「今並不傳。惟…此書尚存于世」 | 「此書」指他書（申鑑），而崇德正論**正列在「不傳」之中**——**判反** |
| **漢蔡中郎集** | 「由官書佚脫，而民間傳本未亡」 | 「佚脫」在前，結論「未亡」在後——**判反** |
| 陸賈新語 | 「此書佚而復出，出亦不全」 | 结论是「復出」，非全佚——過度簡化 |

「此書」「是書」在文言散文中常指**上下文最近提及者**，未必是本條著錄之書。
凡欲用此路，須先做指代消解（辨「此書」所指），非簡單正則所能勝任，**本輪棄之**。

## 第三路：結構化引文，**可用，已施行**

姚振宗逐條每每整段抄錄隋志原文——`隋書經籍志：梁有……亡`——與上一輪處理
隋志注亡書時所用之句式全同。此式之「亡」是**隋志本身之斷言**（梁時尚存、隋時已亡），
非姚振宗的推論，可靠度與上一輪相同。

判準：抓「隋書經籍志：」後之《書名》與terse「……亡。」收尾，且書名須與本條 `title`
有字面交集（去撰人卷數之干擾）。48 條命中，逐條覆核書名皆確指本條，
含語序稍異者（「阮瑀集」「公羊問」「後序」）。

一例可見「亡」不礙 `lost` 判定與後世徵引並存——「典引篇注」姚振宗自注：
「隋志云亡者，但據七錄單行本言之」，而其文仍見於《文選》所引。
此與本庫定例一致：**類書所引之佚文、後人之輯本，皆不改其為全佚**。

## 餘 1,128 條，未動

含三類：

1. 《後漢藝文志》來源，考證散文中確有存佚判斷而**未循 terse 引文句式**者
   （如「北宋時已佚失」一類完整判斷句，散見於長段考證），仍須逐條讀。
2. 其他來源（國史經籍志 105、隋書經籍志 87、隋志考證 84、四庫總目 66……）未查。
3. 志文全無存佚之語者——本屬 `loss_status` 欄位不存在＝「今存或未考」，不必強填。
