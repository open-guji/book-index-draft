# 國史經籍志「一節多書」——已拆，餘 5 節待裁（2026-08-23）

## 體例

焦竑《國史經籍志》著錄同書之異本／異家之注，作

```
《書名》N卷、又M卷、又P卷（撰人甲；撰人乙；撰人丙）
```

「又N卷」各是一部書。匯入時併為一節，於是**一節只繫得一個 work**。

  **全志 97 節，內含著錄 239 條——138 條不可見。**

`chk.py` 查不到這一型：節有 `work_id`、work 有 `indexed_by`，兩側俱全，
只是那 138 部書從來沒進過庫。

## 對位之向

夾註所列之撰人**配「又N卷」諸項**，不配首項。三處可外證：

| 節 | 外證 |
|---|---|
| 《張丘建筭經》二卷、又三卷（李淳風） | 李淳風注本三卷，張丘建原書二卷 |
| 《墨子》十五卷、又三卷（樂臺注） | 隋志「墨子十五卷 墨翟撰」「樂臺注墨子三卷」 |
| 《太公隂謀》一卷、又三卷（魏武帝注） | 隋志「太公陰謀一卷」「太公陰謀三卷 魏武帝解」 |

故三型：撰人數 == 卷數項 → 逐一對位（60 節）；== 卷數項−1 → 首項省撰人、
餘項依序（22 節）；== 0 → 皆無撰人（15 節）。不相配者棄權（1 節，子類下 1401）。

## 由此揭出的錯型：兩書之雜揉

n−1 型之 22 節，匯入一律取**首項之卷數**而配**夾註首撰人**，
於是那一條 work 是兩部書湊出來的——題名撰人是第二項的，卷數是第一項的。

已訂正 17 條：墨子樂臺注 15→3、太公隂謀 1→3、張丘建筭經 2→3、易新林 1→4、
周易占 12→1、風角占 3→7、暢訓 1→100、右事紀歷代崇儒廟學典禮本末 70→8、
次腹賦 37→1、皇極經世衍數支集 50→34、靈寶度人經 3→4、經籍志 4→2、
四分歷 →3、歷法 3→1、相笏經 1→3、甘濾之療癰疽金創方 14→15、樗蒲經 3→1。

## 施行

97 節拆為 239 節。繫連：拆前之 work 歸其應得之項（見上），餘項撞庫，
不中者鑄新。計 **撞庫繫 14、鑄 111、暫不鑄 5**。

### 拆節時必帶 `work_ids`

**`work_ids`（複數）是本庫既有之多書節機制**——備份中三節帶之（占夢書、棋勢、
春秋釋例地名譜），為他車道所繫。初版拆節只帶 `work_id`，把它丟了；今已復原 6 條。
下一輪若再拆別志之多書節，**先查 `work_ids`**。

### 撞庫不得回退到「無撰人」

初版容許「節有撰人而候選 work 無撰人」時按卷數回退，遂令《漏刻經》四節
（梁朱史／陳宋景／祖暅之／梁代）共繫一條、《本草音義》二節共繫一條。
**節有撰人者必以撰人相合乃繫**，否則寧可不繫。

## 餘 5 節待裁

子類上 641／643／644／645／646「《經籍志》N卷（李榮注／韋𠁅玄注／劉仁會注／曹道冲注）」。

**題名是版心竄入**：本節前後皆老子經典（640《老子西升經》、647《老子西升經䟽》、
648《老子存一經》、649《老子中經》、650《老子戒經》），而余道邈、李榮、韋處玄、
劉仁會、曹道冲皆唐人《老子道德經》注家，其書當是《道德經》。

**不鑄之由**：一則「未敢臆補」；二則母條 `1evgpnwiceakg` 之題名亦已作「經籍志」，
正題屬併池車道之權，此處只記不改。**修時須連母條之題名一併正，否則庫中多出五條
題作《經籍志》之老子注。**

## 另一節棄權
