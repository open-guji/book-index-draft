## 二、一個已知的誤判模式：清史稿「不著時代」→ period=qing

《毛詩義疏》被併之條 `1evc5pcnjvcow` 之 `period_basis` 作
「qing_round1:period=qing 且非通用作者 dynasty 唯一为「清」」，
而其著錄原文是清史稿「**不著時代**舒瑗《毛詩義疏》一卷，不著時代。」——
清史稿之「不著時代」條被當成清人之作。該條已隨合併消去（其正主是隋志舒援二十卷本），
但**同一模式極可能還有一批**：凡 `period=qing` 而其唯一著錄源為清史稿、
且著錄原文含「不著時代」者，宜整批復核。

# C 車道 → B 車道：C2b 抽出之撰人朝代（2026-08-23）

C2b 從著錄原文機讀「清李汝珍撰」式者 559 條（通俗小說書目 334，命中率 56.7%）。
C 車道只據此定 `period`，**`authors[].dynasty` 之回填歸 B 車道**，故交棒於此：

- 這 559 條的著錄原文明書撰人朝代，而 `authors` 欄或闕撰人、或有名而無 `dynasty`。
- **已於 2026-08-23 落地**：525 條定代之中，撰人名與原文所抽之名全等者 166 處，
  其 `dynasty` 已一併回填（經使用者授權跨欄）。清單見 `known-issues/C2b-著錄原文定代.json`。
- **仍留給 B 車道者**：名中混入朝代之條——如《欽定兵部處分則例》著錄作「清伯麟等撰」
  而 `authors` 作「清伯麟」，朝代黏進了姓名欄。此類本會話一概不動。
- **注意**：孫楷第解題中之「清末某氏撰」「清無名氏撰」不可據以立撰人，只可定代。
