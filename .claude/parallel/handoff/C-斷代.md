# C 車道 → 單線（SCHEMA）：`period_upper` 判準之一處缺口（2026-08-23，C2′ 調查所得）

**本會話不自行動筆改 `SCHEMA.md`（單線之事），提議如下，請寫 SCHEMA 的會話裁。**

## 缺口

`SCHEMA.md`〈period_upper〉現行之據是「一書見於某志，其時代不得晚於該志」。
此規則對**志書**成立，對**輯佚書目**與**館藏目錄**不成立：

- **輯佚書目**（《玉函山房輯佚書》等）——所錄之書早已亡佚，馬國翰所輯**皆唐以前佚書**。
  以之為上限，得出的是「不晚於清」——真，卻與該書實際時代（漢魏六朝）差了一千年。
  **「被清人輯」恰是「此書唐以前已佚」之強證，方向適相反。**
- **館藏目錄**（《國立故宮博物院善本舊籍》等）——所記為**存世本之抄刻年**，
  非**成書年**。宋人著作之清宮鈔本，上限「不晚於清」為真而無信息量。

**實測波及 3,165 條**（玉函山房 1,196、故宮善本 1,491、其他輯佚 414、萃編 64），
它們因此被擋在 ≤元 域之外，縮小了 A、B 兩類車道可作業之面。

## 提議之條文

> 上限之據須是「該目錄成書時此書已存在」，且該目錄所著錄者須為**當時存世之書**。
> **輯佚書目與館藏目錄不滿足此義**，不得作 `period_upper` 之據：
> 前者所錄之書早已亡佚（其著錄反證此書更早已佚），後者所記為存世本之抄刻年而非成書年。
> 凡 `ai_note` 載「據《玉函山房輯佚書》目錄新建」「從《國立故宮博物院善本舊籍》錄入」者，
> 其上限另求他源（`scripts/period_bounds.py` 六源取最緊者）；無他源者留空。

## 裁定之後 C2a 怎麼辦

1. 玉函山房系 1,196 條——宜整批標 `period_upper: sui-tang`（馬氏輯佚之範圍），
   **但須先抽樣百條自驗**，驗不過不整批標。
2. 故宮善本舊籍 1,491 條——上限撤銷置空，另求他源。**不可整批標任何時代。**
3. 其他輯佚 414＋萃編 64——逐類判。

# C 車道 → B 車道：C2b 抽出之撰人朝代（2026-08-23）

C2b 從著錄原文機讀「清李汝珍撰」式者 559 條（通俗小說書目 334，命中率 56.7%）。
C 車道只據此定 `period`，**`authors[].dynasty` 之回填歸 B 車道**，故交棒於此：

- 這 559 條的著錄原文明書撰人朝代，而 `authors` 欄或闕撰人、或有名而無 `dynasty`。
- C 車道定完 `period` 後，清單出於 `known-issues/`，B 車道可據以補撰人與其朝代。
- **注意**：孫楷第解題中之「清末某氏撰」「清無名氏撰」不可據以立撰人，只可定代。
