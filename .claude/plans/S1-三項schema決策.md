## 決策一：偽託之作的朝代怎麼標

> **2026-08-21 訂正。** 初稿說「459 條」，那個數字是錯的——它數的是**文中出現偽託字樣
> 的記錄**，不是偽書。經指正後逐條讀原文重查，結論改寫如下。

### 初稿錯在哪

三處，都要記下來：

1. **「舊題某某撰」不是偽書。** 那是四庫提要的常規措辭，說的是**撰人之題不確**——
   《別本漢舊儀》「舊題漢議郎東海衛宏敬仲撰」、《香譜》「舊本不著撰人名氏，左圭
   《百川學海》題為宋洪芻撰」。書本身不假。
2. **大量命中說的是別的書，或明確否定。** 《長安志》提要那句「慎喜偽託古書」說的是
   楊慎；《章申公九事》「知非偽託」是否定；《廣博物志》「《三墳》為毛漸偽撰」說的是
   它所引之書；《尉繚》「證其書先秦已成，非後人偽託」更是反證。
3. **「缺 `period`」與偽書毫無關係，初稿不該把它列進證據。** 實測：全庫活 Work
   74,465 條中無 `period` 者 32,578（**43.7%**），而偽託信號那一批只有 22.9% 無
   `period`——這一批反而**比全庫更常有** `period`，因為它們多半有四庫提要。

### 重查之法與結果

兩類分開數，且**都要求所斷之語指向本書**：

- **舊題撰人**：文中「舊題〔朝代〕某某撰」之句，且**所題之人確在本條 `authors[]` 內**
  ——這是交叉驗證，不是猜。得 **327 條**（其中 64 條 `role` 已標「舊題撰」「託名」）。
- **偽書**：文中明指本書為偽（「其為偽託明矣」「即某所偽作也」「蓋書肆偽託之本也」），
  且經兩道否定過濾（非偽／未可謂／似非／非出依託／確為本書）。得 **112 條**，
  逐條讀過，其中尚有十來條是泛論或指他書（《卜法詳考》說的是歷代卜書、《脈經》說的是
  《脈訣》、《大學古本》說的是蘇洵評孟子），**故真數約 100**。

清單見 `.claude/known-issues/偽託與舊題撰人候選.json`。

### 建議（已改）

**只加一個單值欄，不加二值枚舉：**

```json
"authenticity": "forged",          // 省略＝無此疑義
"authenticity_basis": "string（引提要原文，逐條可驗）"
```

**`attributed` 那一值不要了。** 舊題撰人已有現成的表達法且庫中已用了 64 條——
`authors[].role = "舊題撰"`，舊題撰人與實際撰人並列（《西京雜記》即此形態：
`authors[0]` 劉歆·漢·舊題撰，`authors[1]` 葛洪·東晉·撰）。**該做的不是加欄，
是把 327 條裡尚未標 role 的約 263 條補上**——那是資料活，不是 schema 決策。

`period` 之則不變：**標成書時代**，`period_basis` 寫明「舊題某某（某代），實某代作」。

**施行量**：偽書約 100 條逐條核（讀提要原文，不可機械）；舊題撰人約 263 條補 role。

## 決策二：原典與注本的層級

### 問題

一部經有幾百家注。注本該不該獨立成 Work？題名怎麼寫？跟原典什麼關係？

### 實測——**這一項比先秦那份筆記所說的小得多**

庫中**原典錨的機制早已建成並運轉良好**：

| 原典錨 | 繫其下之注本數 | 實物 |
|---|---:|---:|
| 周易 `1evl7l48e27ls` | **1,041** | 14 |
| 偽古文尚書 `1evd3dbcb0nb4` | 386 | 8 |
| 論語 `1ev7w0euvaeww` | 379 | 12 |
| 詩經 `1evl7hsxvr7cw` | 379 | 11 |
| 孝經 `1evl1xugdoikg` | 300 | 8 |
| 左傳 · 漢書 · 禮記 · 周禮 · 儀禮 · 孟子 · 公羊傳…… | 252～93 | — |
| **合計 55 個錨** | | |

關聯詞亦已到位：`contains_text_of` 4,472 ／ `text_carried_by` 4,486，兩側對稱。

**所以缺的不是機制，是把剩下的掛上去：**

| 事 | 量 |
|---|---:|
| `authors[0].role` 為真注疏類者（注 945、傳 36、校 28、述 19、集解 15、集注 12…） | 1,057 |
| 其中題名已含注者名（合規） | 110（已繫原典 100） |
| 其中題名不含注者名 | 947（**已繫原典 306，未繫 641**） |
| 其中題名與某個原典錨**完全同字**（最危險） | **16** |

那 16 條之中還有數條**本身就是錨**——《左傳》`1ev7vo50ar94w` 的 `authors[0]`
是「左丘明·傳」，那不是注本誤題，那就是原典（左丘明傳《春秋》，「傳」是它的體裁）。
**真正需要正名的遠少於 16。**

### 建議：**分兩步，先補關聯，再議正名**

**第一步（可立刻做，零風險）**：把 **641 條未繫原典的注本**補上
`contains_text_of` → 對應原典錨，原典側補 `text_carried_by`。
這是純增量，不動任何既有題名，做完立刻讓「周易有哪些注本」查得全。

**第二步（待第一步做完再議）**：正名。**且只對題名與原典錨完全同字者**，
逐條核——像《周禮注疏》《春秋穀梁傳集解》這種題中已有體裁字樣的**不必改**，
冠上注者名反而累贅。

**寫進 SCHEMA 的規則只有一句**：

> `authors[0].role` 為注／傳／疏／箋／集解之屬者，該 Work 是**注本**，
> 必繫 `contains_text_of` 至其原典 Work；原典側繫 `text_carried_by`。
> 題名**與原典錨完全同字時**須冠注者名以別之，否則從其志書原題。

**不新增欄位。** 這一項用既有的 `role` ＋ 既有的關聯詞就夠了。

## 決策三：一條 Work 到底代表什麼

> **2026-08-21 訂正，本項基本撤回。** 初稿把「從善本目錄錄入的 15,461 條」當成
> 「版本條混進了作品層」，並暗示其為重出。經指正後實查——**它們絕大多數不是重出。**

### 實查

對 15,185 條（活記錄）逐條查「全庫有無同題他條」：

| | 量 | 佔比 |
|---|---:|---:|
| **全庫無同題他條——本條即該書之唯一記錄** | **12,272** | **81%** |
| 有同題他條而撰人不同（多為同名異書） | 2,390 | 16% |
| 有同題他條而一方無撰人（須逐條核） | 516 | 3% |
| 有同題他條且**撰人相同**（真重出之嫌） | **7** | 0.05% |

**八成是庫中該書的唯一記錄。** 所謂「先建 work、後補 book」的做法在資料上完全成立：
這些 Work 是正當的作品記錄，只是它們的來源是一部版本目錄而已。初稿據 `ai_note` 的
「從某某目錄錄入」一句就推斷其性質，是**把來源當成了實質**，錯。

那 7 條同題同撰人的，**其中 4 條（2 對）是本會話 8/21 缺字訂正所造成的**：
《訒庵集古印存》與《恆軒所見所藏吉金錄》各有二條，同出故宮善本目錄，
當初未能去重是因為**兩條的缺字寫法不同**——一條首字作 U+FFFD 替換符、一條作
私用區 PUA 字元，彼此比對不上，故各建一條。8/17 訂正 PUA 那條、8/21 訂正
U+FFFD 那條，題名遂相同而暴露。**本會話已併此二對**，餘 3 條與 516 條交 B 車道。

### 建議（已改）

**不加 `record_kind` 欄。**

初稿的三分（作品／著錄／版本）在概念上仍然成立——《老子》與《道德經》那個死結是真的
——但它是**個案**，不是 15,461 條的通則。為一百來個個案加一個要填七萬條的欄，
不划算；而真要分辨時，`books[]` 與 `indexed_by[]` 的有無已經夠用。

**改為記一條體例即可**（寫進 `SCHEMA.md`，不新增欄位）：

> 一部書先建 Work、後補 Book 是正常次序。Work 之來源為版本目錄（故宮善本舊籍、
> 續修四庫、存目叢書、中華再造善本之屬）者，**仍是作品記錄**，不因來源而降格。
> 同一部書在同一部版本目錄中有數部藏本者，應為**一個 Work、數個 Book**；
> 匯入時因題名缺字而未能去重者，訂正缺字後須回頭查同題。

最後那一句是本輪付出代價換來的——缺字訂正會讓潛伏的重出浮出來，**訂完要回頭查**。


決策二不新增欄位（用既有 `role` ＋ 既有關聯詞）。
決策三不新增欄位（改為記一條體例）。

初稿說要加三個欄（`authenticity` 二值 ＋ `record_kind`），**經兩處指正後縮為一個單值欄**。

**貫串的一條體例仍然成立：只標異常，不標正常。** 庫中既有先例——`loss_status`
之 `extant` 全庫只有 1 條，省略即今存。
