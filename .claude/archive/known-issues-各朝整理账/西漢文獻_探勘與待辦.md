# 西漢文獻探勘與待辦

2026-08-11。範圍：`period == "qin-han"`（1634 條）中撰人朝代可判為西漢
（前206–8）之文獻。

## 一、規模現實：與先秦組、秦朝組截然不同的量級

先秦組（period=pre-qin）269 條、秦朝組（dynasty=秦）16 條，皆可逐條
通讀。漢代文獻則完全是另一量級：`period=qin-han` 共 1634 條，其中
**絕大多數僅籠統標作「漢」（原 942 條）或「東漢」（483 條），細分
「西漢」者原僅 5 條**——換言之，本庫對漢代文獻長期未做西漢／東漢
之區分，此為進入逐條分析前必須先解決的結構性障礙，而非可直接沿用
先秦組「拿到清單就逐條讀」的方法。

## 二、本輪核心發現：Entity 早有精確分判，Work 層級卻未同步

比對 942 條「漢」籠統標記之 Work 與其 authors[0].entity_id 所指
Entity 後發現：**Entity 記錄中，有相當大一部分人物早已被精確分判為
「西漢」或「東漢」**（推測係先前 CBDB 比對／人工校訂之成果），但這
個判斷從未回寫到 Work 層級的 authors[0].dynasty——Work 端長期停留在
匯入時的籠統「漢」。這是一個此前先秦組、秦朝組皆未出現過的**新問題
類型**：不是文獻本身重出或誤植，而是「已完成的判斷未傳播」。

### 處理方式與結果

先對 Entity 記錄逐一核校其 dynasty 是否確為「西漢」或「東漢」（見下
節「順帶查出之錯誤」），排除少數本身有誤者後，將 Work.authors[0].
dynasty 為籠統「漢」、且其 entity_id 所指 Entity.dynasty 為精確
「西漢」或「東漢」者，同步覆寫。詳見 `scripts/sync_han_dynasty_from_
entity.py`。

**結果**：

| | 同步前 | 同步後 |
|---|---|---|
| 西漢 | 5 | 156 |
| 東漢 | 483 | 618 |
| 漢（籠統） | 942 | 652 |

僅同步「Entity 精確、Work 籠統」單一方向，不觸碰相反方向（Work 已精
確而 Entity 反較籠統，如鄭玄／荀爽等大宗東漢經學家之 Entity 仍作
「秦漢」廣義標記——此為 Entity 層級尚待精修之既有缺口，非本輪引入之
新問題，且 Work 層級本身已正確，不受影響）。

## 三、順帶查出之獨立錯誤（與斷代粒度無關）

比對 Entity／Work 兩層 dynasty 時，另外查出六個獨立問題，逕行修正：

1. **賈逵三方分裂**——東漢經學家賈逵（30–101，以《左傳》《國語》學
   名家）之 23 部著作，因 CBDB 自動比對錯誤，分裂繫連於三個 Entity
   （其一 dynasty 誤填「三國魏」，然其自身 cbdb_source 欄位明言比對
   候選為「东汉贾逵」，自相矛盾）。核對三方作品書目後確認同屬一人，
   已合併為一，dynasty 訂正為「東漢」。
2. **漢高祖實録**（蘇逢吉撰）、**𣈆高祖實錄**（竇貞固撰）——二人皆
   五代後漢／後晉宰相，《國史經籍志》著錄語「漢蘇逢吉」「漢竇貞固」
   之「漢」指五代後漢，非秦漢之漢。竇貞固之 Entity 記錄早已由前人
   訂正為「後漢」／`period=five-dynasties`，然對應 Work 從未同步，
   長年停留 `period=qin-han`——與本節主題發現同一模式，一併訂正
   （蘇逢吉之 Entity 亦一併訂正）。
3. **喪服經傳王氏注**（王肅撰）——王肅（195–256）為三國曹魏經學家，
   非漢人，dynasty「漢」純屬誤植，訂正為「三國魏」。
4. **十一家注孫子**（`1evjr3jstkwzk`）——原 authors 作「曹操唐杜牧」，
   將漢魏之際曹操與唐代杜牧二人姓名／朝代誤合為一條。十一家注實為
   宋吉天保所輯（曹操、李筌、杜牧等十一家），已改 authors 為吉天保
   （宋，輯），period 隨之訂正為 song。
5. **張禹、嚴遵二 Entity 之 dynasty 誤植**——張禹（安昌侯，卒前5年，
   注《論語》）、嚴遵（嚴君平，著《老子指歸》）皆確為西漢人，然其
   Entity 記錄之 dynasty 因 CBDB 自動比對誤作「東漢」，已訂正為
   「西漢」（連帶其所繫 Work 於本輪同步中一併訂正）。

## 四、逐條核校 90 組「Entity=西漢／東漢、Work=籠統漢」候選之方法

同步前，先取得所有候選之（人名、Entity dynasty、entity_id）去重清單
（約 90 組，見下），逐一以史實核校（生卒年、任官、著作年代），僅
張禹、嚴遵二組確認有誤（見上節），其餘約 88 組核校無誤，方執行批次
同步。此法之要點：**縱使涉及數百部作品，核校對象實為數十位歷史人物
（非數百部作品各自考證），故仍可逐條窮盡查核，未犧牲精度**。

## 五、分期計畫

652 條籠統「漢」細分為：

- **382 條有 entity_id，然 Entity 本身 dynasty 亦僅作籠統「漢」／
  「秦漢」／缺值**——涉及 164 位歷史人物，按出現頻次排序，前 20 位
  即覆蓋約 200 條。
- **264 條無 entity_id**——其中 73 條為「佚名」（無法以作者身分判斷，
  需逐條核讀著錄内容），191 條為具名作者，其中多與上一批同名（如
  鄭玄、劉向、賈誼等），顯示 entity 繫連本身不完整。
- **7 條屬斷代邊界個案**（阮瑀、應瑒、蔡琰、丁廙等建安文人卒年逼近
  漢魏禪代之際），核校後認為現狀屬史學上可接受之簡化，不強行改動。

**階段一（✅ 已完成）**：處理「Entity 有、dynasty 籠統」382 條中出現

entities.py`。共修正 213 條 Work、21 個 Entity。順帶查出並訂正二個

## 六、順帶查出之斷代邊界誤植（階段一新增）

- **孔鮒**（`1ev3bb72w1z40` 孔叢子釋文、`1ev3ba9imamtc` 小爾雅、
  `1evjy54xuvlkw` 孔叢子七卷釋文一卷題）——孔子八世孫，仕陳勝為
  博士，卒於秦二世元年（前209），未及見漢，dynasty「漢」有誤，

- **諸葛亮前／後出師表**（`1evhmgnlyc9hc`／`1evhmgnr0y39c`）——諸葛
  亮（181–234）為三國蜀漢丞相，非秦漢帝國意義之漢代人，原 dynasty

  period 為 three-kingdoms（本庫查無「蜀漢」既有慣例，此為新立）。

## 收尾（2026-08-24，兩漢H8）

- 撰人 dynasty 缺鍵／None 者，可確證之 70 人名（京房→西漢、鄭玄→東漢之屬）批量補正，
  波及 132 條；「宋均」36 條因注緯之宋均與後漢宋均是否一人歷有爭議（惠棟等主魏宋均說，
  姚振宗三國志按語亦存疑），不強判，維持缺代。
- 籠統「漢」細化 25 人名（樊光、許淑、李步昌、劉氏諸王之屬）。收尾後：西漢 499／東漢 931／
  籠統漢 82／撰人無代 71／無撰人 203——餘者皆漢志詩賦略無考之人與出土佚名，屬「未考」常態。
- 壞名六案順帶訂正：伏無忌（忌字竄題）、衛宏（著錄語全文誤入名欄）、崔瑗（暖訛）、
  孔穎達二條（唐前綴／朝代誤漢）、尚書條垃圾撰人「南以前所」；忌伏侯古今注、別本漢舊儀
  二條同書併一。

本檔遺留至此收束；佚名出土文獻無內證者依原判維持挂起。
