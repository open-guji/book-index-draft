# 已知缺陷：Work→Book 單向 3,944 條（發現於明代整理，非明代專屬）

**2026-08-24 明代整理過程中查出，未處理**——與本輪明代之整理無涉，樣本（如
《北窗炙輠錄》Book `11q37s9obigow`）出自宋代／隋唐桶，疑源自並行會話近日
「隋唐統一升格」「宋代 G3/G6/G5b/G7」等批次之升格 sweep 未竟全功。

## 現象

`chk.py`「Work→Book 單向」由基線 0 升到 3944。樣本檢視：Book 檔（draft 側）
之 `work_id` 仍指向一個**未升格**的草稿 Work，而 production 側**已有一個
不同的**、已升格之 Work 的 `books[]` 陣列同時引用了同一個 Book id——即同一
Book 被草稿與 production 兩側各自的 Work 認領，形成單向。

## 待辦

- 逐一核對這 3944 條，判明是升格 sweep 遺漏抑或別的原因（如 Book 本應歸屬
  已升格之 Work 而 draft 側 work_id 未隨升格改寫）。
- 不宜在明代車道順手改——涉及宋代／隋唐等桶之草稿與 production 資料，
  應由其原車道或專項處理，以免與並行會話衝突。
