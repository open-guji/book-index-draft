# 乙2 兩千條之審閱（2026-08-23）

問：這兩千多條，哪些有撰人、哪些沒有？沒有的，名字就真的再無別的來源了嗎？

答：**前次解析把最要緊的一宗材料丟了。** 補回之後，「真無他據」的只有 61 條。

## 一、先說丟了什麼

`經義考待裁.json` 的 `first_note` 只存二三十字。覆按 kanripo 原文才知道，那
是截斷之餘——朱彝尊於每條之下所輯的**諸家論斷**（劉歆曰、荀勗曰、崇文總
目、國史志、中興書目、唐會要、某人序、某人志墓……）動輒數百字，最長一條
一萬五千餘字，前次一概棄去。

全書 9,115 條，有論斷者 5,623 條，論斷總計 **129 萬字**。

這正是「庫中無其書、志亦不著」那批條目僅有的憑據：

| 標目 | 原本判為 | 論斷所載 |
|---|---|---|
| 學易說約 | 無撰人 | 《閩書》：丘富國，字行可，建安人，受業朱氏之門，宋亡不仕，著《周易輯解》十卷、《易學說約》五篇 |
| 九經發題 | 無撰人 | 《先民錄》：唐仲友，字與政，金華人，紹興辛未進士 |
| 儀禮經傳通解續 | 無撰人 | 張萱曰：宋淳祐間信齋楊復著…凡十四卷八十一門 |
| 漢易中孚義 | 無撰人 | 朱氏按：《公羊》「隕霜不殺草」何休注引《易中孚記》文，是漢有其書矣 |
| 河洛內記 | 無撰人 | 右見《抱朴子·遐覽篇》 |

**撰人、里貫、時代、出處，都在裡頭。**

重取之法見 `scripts/jyk_fetch_source.py`，全文另存
`.claude/known-issues/經義考論斷.json`（以頁次＋標目為鍵，可與待裁清單對接）。
原文快取在 `build/`（已入 .gitignore，重跑腳本即得）。

原文之體例：**縮排即層**——0 條目首行／2 著錄／3 存佚／1 論斷／4 按語。
一條論斷屢跨數行並跨半葉，同層之連行當並為一段；標目中的 `(名/)` 是夾注之
式，須歸一為 `（名）` 方與待裁清單相合。

## 三、網上查得到什麼

試搜數條，所得甚薄，聊記於此以省後人之力：

- 《易源奧義》（保八）——查得確在《四庫全書》經部易類，是存世之書。可用。
- 《古微書》——查得孫瑴輯，三十六卷，含《河圖緯》《洛書緯》等十種，正是
  上文緯書之所歸。可用。
- 保八其人（元代色目人易學家）——通用搜尋只返回「色目人」制度之泛論，於
  其人其書無所得。

**通用網搜於此類條目性價比甚低**：這些是十七世紀書目中的亡佚之書，網上流通
的多是《四庫》著錄與維基條目，凡網上查得到的，《經義考》自己的論斷多半已
經說了，且說得更準（有出處、有引文）。**手上這 129 萬字才是正路。**

## 四、由此該怎麼做乙2

1. **先補標目解析與撰人**：可補之 111 條（標目未解 69＋論斷可考 46，去其重）
   逐條正之。此是最實在的一步。
2. **建 work 時繫 `period`**：879 條有年號或 Entity 之據者可繫，逐條記其
   `period_basis`（引某論斷之某年號，或庫中 Entity 唯一）。餘者仍不繫。
3. **論斷入 `indexed_by[].summary` 或另立欄**：現行 summary 只放著錄語
   （「宋志十卷」），論斷之長非其所能容。宜另議其所歸——此事須先定 schema，
   不可各道各作一式。
4. **本無撰人之 41 條照建**：亡名氏是史實，不是缺陷。
5. **真無他據之 61 條照建**：題、卷數、存佚之判仍在，仍是一條著錄。
