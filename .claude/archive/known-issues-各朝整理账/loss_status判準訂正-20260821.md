# `loss_status` 判準訂正：輯本改判 `partially_extant`

2026-08-21。使用者指出 SCHEMA〈`loss_status` 枚舉〉之 `lost` 判準有誤，覆核屬實，已改 SCHEMA 並遷移資料。

## 一、原判準與所宣之軸不自洽

SCHEMA 開篇定軸：

> 一軸而已：**本書之文今日尚存幾何**

而 `lost` 原判準：

> 原書無一存。**類書所引之佚文、後人之輯本，皆不改其為全佚**——「今存者為清孫星衍校輯本」仍是 `lost`

有佚文數條存世，「文今日尚存幾何」之答即非零。**兩句用的不是同一個軸。**

原判準實際所用之軸，從「殘存不用 `fragmentary`」一段可以看出：

> 西方書目學之 fragmentary 多指「只靠他書徵引之斷片存世」，那正是本庫的 `lost` 加輯佚檔，與 `partially_extant` 相反

即設計者心中 `partially_extant` ＝**傳本殘存**（本子尚傳而缺卷），`lost` ＝**傳本斷絕**（本子已亡，只剩他書徵引）。
這是「傳本是否斷絕」軸，非「文存幾何」軸。定義句寫錯了軸。

## 二、改後 `lost` 不致喪失判別力（實測）

| | 改前 | 改後 |
|---|---:|---:|
| `lost` | 4130 | **2497** |
| `partially_extant` | 75 | **1707** |
| `extant` | 4 | 4 |

`lost` 尚餘二千餘條，且所餘者是真正「志書著錄其名而已，一字不存」的——
比原先含混的「傳本斷絕」更精確、更有用。

反觀 `partially_extant` 改前僅 **75** 條：可見「傳本殘存 vs 賴輯佚」這個區分，
本來就不是由 `loss_status` 承載的，而是由 `fragments` 檔承載。
SCHEMA 自己也寫著「**有輯本**不是存佚狀態而是補救。由 `fragments` 檔之有無與 `collectors` 是否非空導出」。

故原 `lost` 排除輯本之規定，是在一個宣稱「文存幾何」的欄位裡夾帶「傳本斷絕」，
而該資訊本已有專欄承載。

## 三、代價與化解

**代價**：目錄學傳統之「佚」指傳本失傳（四庫、姚振宗、章宗源皆如此用），
改後本庫之 `lost` 與志書原文之「佚」字不再對應。

**化解**：本已有機制。`indexed_by[].attested_status` / `attested_status_raw`
專記「該目錄書對此書存佚之判」（原文「存／闕／佚／未見」），
且 SCHEMA 明言「**不得逕改本記錄之 `loss_status`**」。二軸本已分立，改後反更乾淨：

| 問題 | 歸屬 |
|---|---|
| 志書說存還是佚 | `indexed_by[].attested_status_raw` |
| 本庫判文存幾何 | `loss_status` |
| 有無輯本、誰輯、輯幾條 | `fragments` 檔 ／ `collectors` |
| 傳本是否斷絕 | 由「`partially_extant` 且有 `fragments` 檔」導出 |

## 四、遷移（1633 條）

| 批 | 條數 | 據 |
|---|---:|---|
| 有輯佚檔者 | **1197** | 檔內有輯家／佚文／諸家所稱條數，皆非空殼（1226 檔全實） |
| 《清史稿·藝文志》輯佚類目 | **406** | 該志各部類下有「輯佚」子目，著錄清人所輯之本。**這批原本正是「因為有輯本」才被判 lost 的**——原 ai_note 自記「據 ai_note 自身『輯佚條目』之批次分類標記（本庫此標記 143/143 既有先例皆為 lost）」，在新判準下恰好相反 |
| 文中明載有輯本 | 18 | 「張氏《百三家》…輯本一卷」「嚴氏文編輯本一卷」之類 |
| 文中明載輯家輯有本書 | 10 | 馬國翰／嚴可均／孫星衍等 |
| 文中明載佚文存世 | 1 | 《伯象先生》：《太平御覽》卷八一一存其唯一佚文 |
| 今存殘卷 | 1 | |

另刪 1 條誤判：《玉函山房輯佚書史編》`1evincoot89vk`——本條是輯佚叢書**本身**，
清同治補刻本以下傳世不絕，「輯佚」是其性質而非謂其已佚。

## 五、刻意未改者

**67 條**：前輪普查已逐條判明「文中雖見輯家之名而不指本書之輯佚」者，保持 `lost`。
其 ai_note 已載其據（如「本條之文見輯家之名（嚴可均）而無一語言其輯此書——
名之出現多在考證之引述中，引述不等於輯之」）。

**「《X志》存一卷」不作據**。姚振宗一類考證中「《隋志》存一卷，兩《唐志》仍二卷」
說的是**當時志書著錄之卷數**，非今日存世之數。初掃誤收 47 條，已剔除；
只取「今存」「輯存」「輯得」等明指今日者。

## 六、待辦

改判為 `partially_extant` 而**尚未立輯佚檔**者 **436 條**——
其 ai_note 已標「本條尚未立輯佚檔，待補」。補檔後可由檔內 `collectors`／`fragments` 自驗。
